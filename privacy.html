日本語

1. データの取り扱い

ShareOrBackup(以下「本アプリ」)は、ファイル共有・バックアップをユーザーの端末およびローカルネットワーク内でのみ行います。ファイルの内容や認証情報が開発者のサーバーに送信されることはありません(開発者はサーバーを運営していません)。

2. 端末内に保存される情報

フォルダ設定・リンク情報・転送履歴はユーザーの端末内のみに保存されます。接続先の認証情報は端末内の暗号化ストレージに保存されます。

3. ネットワーク通信

同一ネットワーク内のデバイス検出およびファイル転送のための通信のみを行い、外部のサーバーへの送信は行いません。通信は可能な場合TLSで暗号化されます。

4. 課金

Pro版の購入にはGoogle Play決済を利用します。決済情報はGoogleが処理し、開発者がクレジットカード情報等を取得することはありません。

5. 広告・解析

アプリ内では広告の表示および第三者による利用解析を行っていません。なお、本ウェブサイト(sharebackup6.github.io)では、利用状況の把握のために Google Analytics を利用しています。Google Analytics は Cookie を使用してアクセス情報(閲覧ページ・参照元・おおまかな地域など)を収集しますが、個人を特定する情報は含まれません。

6. 権限の利用目的

通知、バックグラウンド動作、Wi-Fi状態の取得等は、ファイル同期・バックアップ機能のためにのみ使用します。フォルダへのアクセスはユーザーが選択したフォルダに限定されます。

7. お問い合わせ

sharebackup6@gmail.com

English

1. Data handling

ShareOrBackup (the "App") shares and backs up files only on the user's devices and local network. File contents and credentials are never sent to the developer's servers (the developer operates no servers).

2. On-device storage

Folder settings, link information, and transfer history are stored only on the user's device. Credentials for remote targets are stored in the device's encrypted storage.

3. Network communication

The App communicates only for device discovery and file transfer within the local network. Nothing is sent to external servers. Communication is encrypted with TLS where available.

4. Purchases

Pro purchases use Google Play billing. Payment information is processed by Google; the developer never receives credit card details.

5. Ads and analytics

The App itself shows no ads and performs no third-party usage analytics. However, this website (sharebackup6.github.io) uses Google Analytics to understand usage. Google Analytics uses cookies to collect access information (pages viewed, referrer, approximate region, etc.) and does not include personally identifying information.

6. Permission usage

Notifications, background operation, Wi-Fi state access, and similar permissions are used solely for file sync and backup features. Folder access is limited to folders the user explicitly selects.
